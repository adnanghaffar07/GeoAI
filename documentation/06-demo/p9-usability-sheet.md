# P9.6 Usability session: task sheet and notes form

**For:** the team lead and 1–2 colleagues who have not used the app. **Time:** about 30 minutes each.
**Host (owner):** give the person this sheet and a manager account in a test organization; say "think aloud"; do **not** help unless they are stuck for 2 minutes; write notes below.

## Tasks (read them one at a time)

| # | Task for the person |
|---|---|
| T1 | Sign in, then find the project "Downtown streets" (or the test project). |
| T2 | Upload 3 road photos to that project. |
| T3 | Send the new photos to the AI check and wait until it has finished. |
| T4 | Open the first suggestion, decide whether it is a real problem, and save your decision. |
| T5 | Plan an inspection of a verified problem for a colleague, due next Friday. |
| T6 | Download a CSV report of the verified problems. |
| T7 | Open Road risk. Which road should be inspected first, and why? |
| T8 | Plan an inspection of that road. |
| T9 | Ask the road-risk assistant: "Will the weather this week affect our roads?" |
| T10 | Go back to the home page without using the browser's Back button. |
