# ml/

AI model work for P8 (plan: `documentation/04-design/ml-baseline-plan.md`). It has its **own
dependencies**, separate from the backend, so the API server never installs the training
stack (PyTorch etc.) until a model is actually integrated.

| Folder | Purpose | Added in |
|--------|---------|----------|
| `config/` | Pass marks the evaluation reads (`acceptance-thresholds.yaml`, PLACEHOLDER) | P8.0 |
| `data_prep/` | `fetch_rdd2022.py`: download, check, unpack without the US part, count | P8.1 |
| `data_prep/` | `split_rdd2022.py`: clean, remove duplicates, split (test = Czech, locked), shrink photos, COCO annotations | P8.2 |
| `splits/v1/` | The locked P8.2 split: which photo is in training, validation and test, plus `split-manifest.json` with fingerprints (lists only, no photos) | P8.2 |
| `reports/` | Small results files, e.g. `inventory.json` from P8.1 (counts only, no photos) | P8.1 |
| `tests/` | Tests for the ML scripts (run on fake data) | P8.1 |
| `data/` | Downloaded datasets and splits (**never committed**) | P8.1 |
| `training/` | `train_frcnn.py`: trains Faster R-CNN (ResNet-50 FPN) on the P8.2 split; saves progress to Drive; never reads the test set | P8.4 |
| `evaluation/` | `metrics.py`: the scoring rules (same class + 50% overlap, recall, precision, best-F1 cut-off, AP50) | P8.4 |
| `evaluation/` | `evaluate_test.py`: the one-time final test on the locked Czech test set; PASS / FAIL / NOT ENOUGH EVIDENCE per class against `config/acceptance-thresholds.yaml`, plus dark/blurry/clean-road and CPU-speed checks; writes `test-report.md` | P8.5 |
| `notebooks/` | Google Colab notebooks, generated by `make_notebooks.py` with the scripts built in (no Drive upload needed). Never edit a notebook by hand | P8.1 |
| `models/` | Trained weights (**never committed**) | P8.4 |

The app-side model contract and the TEST DETECTOR live in `backend/app/ai/`
(`contract.py`, `registry.py`, `stand_in.py`).

Datasets and model weights are **never** committed (see `.gitignore`). Their source,
version, download date and licence are recorded in a dataset card instead.

## Running the tests

```bash
cd ml
python -m venv .venv && .venv/bin/pip install pytest -r requirements-data.txt -r requirements-train.txt   # Windows: .venv\Scripts\pip
.venv/bin/python -m pytest -q
```
